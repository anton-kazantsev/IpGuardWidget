# IP Guard — виджет запуска Claude Code для Windows 10/11

Плавающий виджет 360 × 288 px (360 × 351 px, когда показана заметка о блокировке) в окне
шириной 392 px: показывает текущий IP и страну, проверяет доступность Claude Code и запускает его
в Windows Terminal. Над карточкой могут появляться баннер обновления (+80 px по высоте окна —
баннер 72 + зазор 8) и панель «Что нового» (+356 px). Если страна — Россия, кнопка блокируется
с подсказкой «Включи VPN»; после смены IP виджет сам перепроверяет страну и разблокирует кнопку.

## Что нового в 1.2

- кнопка проверки обновлений в шапке рядом с лого — с подсказкой и состоянием «идёт проверка»;
- баннер обновления над карточкой: появляется только при новом релизе на GitHub;
- панель «Что нового» с пунктами из раздела `## Что нового` README на теге релиза;
- скачивание exe с прогрессом и отменой прямо из баннера;
- «Скрыть до следующей версии» — отложенный тег запоминается в настройках;
- в подвале после ручной проверки на 5 секунд появляется `Обновлений нет · v1.2`;
- проверка IP каждую **1 секунду** при блокировке, без сети и пока запущен Claude Code, и раз в **20 секунд** при включённом VPN;
- при потере VPN или сети виджет показывает предупреждение («VPN отключён — Claude Code продолжает работать» / «Нет сети — команды не уходят»), сессия не прерывается, блокируются только новые запуски.

## Что нового в 1.1

- версия в шапке карточки — `IP GUARD v1.1`;
- кнопка сворачивания в трей в шапке: виджет прячется, остаётся иконка в трее;
- выбор оболочки прямо в карточке: строка `ОБОЛОЧКА` с чипом, список `cmd` / `PowerShell` / `напрямую` раскрывается слева, шеврон поворачивается, выбор запоминается;
- иконка в трее отражает состояние: акцентная при VPN ON, серая при VPN OFF;
- опрос стал быстрее: Россия — каждые 5 с (поймать включение VPN), VPN включён — каждые 20 с (поймать смену IP);
- сторож запуска: пока VPN выключен, `claude` из любого терминала не запускается, а виджет показывается;
- карточка выросла до 360 × 288 px (360 × 351 с заметкой), окно — 392 × 320;
- подвал карточки: `Откроется Terminal`, ссылка справа — `Обновить IP` (`Повторить`, когда данных нет).

## Стек

- **C# / .NET 10 (LTS), WPF** — один самодостаточный `.exe`, без установленного .NET и без WebView2.
- Без NuGet-зависимостей: HTTP — `HttpClient`, JSON — `System.Text.Json`, трей — Win32 `Shell_NotifyIcon`,
  меню — нативное `TrackPopupMenu`, автозапуск — реестр.
  
## Сборка

Проект лежит в `C:\pet-projects\IpGuardWidget`. Нужен только
[.NET SDK 10](https://dotnet.microsoft.com/download) (на машине разработчика ставится
командой `winget install Microsoft.DotNet.SDK.10`).

```powershell
cd C:\pet-projects\IpGuardWidget
dotnet build -c Debug                 # отладочная сборка
dotnet run -c Debug                   # запуск
```

Публикация одним exe — single-file, ReadyToRun и сжатие уже прописаны в `IpGuardWidget.csproj`,
поэтому достаточно одной команды (её же выполняет `build.ps1`):

```powershell
dotnet publish -c Release -r win-x64 --self-contained true
```

Собранный файл — `bin\Release\net10.0-windows\win-x64\publish\IpGuardWidget.exe`, готовый релиз
кладётся в `dist\IpGuardWidget-v1.2.exe` (~59 МБ, FileVersion 1.2.0.0). Его можно просто
скопировать на другую Windows 10/11 машину и запустить.

## Запуск

| Команда | Что делает |
|---|---|
| `dist\IpGuardWidget-v1.2.exe` | показывает виджет в правом нижнем углу |
| `IpGuardWidget.exe --tray` | стартует свёрнутым в трей (используется автозапуском) |
| `IpGuardWidget.exe --simulate NL` | имитация страны (NL / RU / DE / US / IPV6 / SLOW / OFFLINE); `LOSS` — пропадание и возврат сети, `VPNOFF` — выключение и включение VPN (для проверки предупреждения о работе без защиты) |

Повторный запуск exe не открывает второе окно: первый экземпляр поднимается на передний план.

## Поведение

- **Шапка**: логотип, кнопка проверки обновлений рядом с лого (`26 × 26`, подсказка «Проверить
  обновления», акцентная заливка и белая иконка, когда обновление найдено, полупрозрачная на
  время проверки), статус-пилюля — `VPN ON` (зелёная), `VPN OFF` (жёлтая), `ПРОВЕРКА`,
  `НЕТ СЕТИ` — и кнопка сворачивания в трей: виджет прячется, остаётся только иконка в трее.
- **Проверка IP**: при старте и дальше по состоянию — каждую **1 секунду**, пока страна —
  Россия, пока нет сети и пока запущен Claude Code (чтобы сразу заметить пропажу VPN), и раз
  в **20 секунд**, когда VPN включён и Claude Code не запущен (чтобы поймать смену IP).
  Плюс внеочередная проверка, когда Windows сообщает о появлении сети.
- **Источники данных** (без API-ключей): `api.ipify.org` → `api64.ipify.org` → `ifconfig.me`
  для IP; `ipapi.co` → `ipwho.is` для страны и города. Если IP не изменился, страна берётся
  из прошлого ответа и геосервис не запрашивается. При сбое показывается последний известный IP
  и пометка «Нет сети».
- **Перед запуском** IP перепроверяется, если последним данным больше **45 секунд**.
- **Выбор оболочки**: в карточке над `Run Claude` строка `ОБОЛОЧКА` с чипом. По клику слева
  от чипа раскрывается список `cmd` / `PowerShell` / `напрямую` (шеврон поворачивается влево),
  выбор сохраняется в настройках и подписывает чип. Пока ничего не выбрано, на чипе
  `Выбери оболочку`, а запуск идёт через `cmd`. Та же настройка есть в меню трея.
- **Запуск Claude**: `wt.exe new-tab --title "Claude Code" -d "<папка>" cmd.exe /k "<claude>"`.
  Вкладка остаётся открытой после выхода Claude; `PowerShell` — `-NoExit -Command claude`,
  `напрямую` — сам `claude.exe` без оболочки. Если Windows Terminal не установлен — обычное
  окно консоли. Поддерживаются `claude.exe` (нативный установщик) и `claude.cmd` (npm).
  Если Claude не найден, виджет показывает подсказку с командой установки.
- **Сторож запуска**: пока приложение запущено и VPN выключен (страна блокируется) или пропала
  сеть, `claude`, запущенный из любого терминала, сразу завершается, а виджет показывается —
  даже если был свёрнут в трей. Когда VPN включён, запуск не трогается; процессы, работавшие
  до старта виджета, тоже остаются в покое.
- **Работа без VPN и автосворачивание**: если VPN или сеть пропали, пока Claude Code работал,
  виджет **не гасит** его — сессия продолжается, — а показывает себя с заметкой «VPN отключён —
  Claude Code продолжает работать» / «Нет сети — команды не уходят» и пишет в подвале
  `VPN отключён · Claude Code работает` (при потере сети в подвале остаётся обычное
  `Нет сети · данные в HH:MM`, при обычном блокировании по стране — `Claude Code заблокирован`).
  Если Claude Code в этот момент не запущен, виджет не всплывает и заметка не появляется.
  Когда состояние снова разрешает запуск, заметка становится зелёной — «VPN включён — можно
  продолжать» после потери VPN и «Связь восстановлена — можно продолжать» после потери сети, —
  и через **3 секунды** окно сворачивается в трей с запоминанием позиции. Любой клик или
  перетаскивание в окне отменяет автосворачивание; если состояние было заблокировано ещё при
  старте виджета, запущенный ранее Claude Code не трогается. При выключенном VPN новые запуски
  Claude Code по-прежнему не проходят — такой процесс сразу гасится (см. «Сторож запуска»).
- **Окно**: без рамки, always-on-top, перетаскивание за карточку, закрытие/Esc — в трей,
  позиция запоминается по нижнему правому углу карточки, второй экземпляр поднимает окно.
  В подвале карточки — `Откроется Terminal` и ссылка `Обновить IP` справа (когда данных нет —
  `Повторить`).
- **Обновления**: через 3 секунды после старта и дальше каждые **6 часов** виджет спрашивает
  GitHub Releases API репозитория `anton-kazantsev/IpGuardWidget` и сравнивает версию из тега
  релиза (`v1.2.1` → `1.2.1`) с версией exe. Баннер над карточкой появляется только если релиз
  новее; ошибка, оффлайн, 404 или таймаут только пишутся в лог — окно не меняется. Пункты
  панели «Что нового» берутся из раздела `## Что нового` в README репозитория на теге релиза
  (если раздела нет — из тела релиза). «Скрыть до следующей версии» запоминает тег в настройках
  (`PostponedUpdateTag`). Кнопка в шапке карточки рядом с лого и пункт трея «Проверить
  обновления» запускают проверку вручную; если обновлений нет, в подвале на 5 секунд появляется
  `Обновлений нет · v1.2`, а если проверка не удалась (нет сети, 404, таймаут) — только запись
  в лог, подвал и баннер не меняются.
- **Трей**: иконка акцентная при VPN ON и серая при VPN OFF; левый клик — показать/скрыть,
  правый клик — меню: обновить IP, проверить обновления, всегда сверху, автозапуск, оболочка
  запуска (cmd / PowerShell / напрямую), папка запуска, сбросить позицию, выход.
- **Автозапуск** (по желанию): `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` → `"...\IpGuardWidget.exe" --tray`.

## Где лежат данные

- Настройки: `%APPDATA%\IpGuardWidget\settings.json`
- Лог: `%APPDATA%\IpGuardWidget\ipguard.log` (+ `ipguard.old.log` после ротации на 512 КБ)

Позиция хранится в физических пикселях и проверяется по реальным рабочим областям мониторов,
поэтому виджет не теряется при смене конфигурации экранов и на мониторах с масштабом 125/150%.
Если окно всё же оказалось вне экрана: правый клик по иконке в трее → «Сбросить позицию»
(или удалить `settings.json`).

```

dist/                     готовый IpGuardWidget-v1.2.exe
```

## Ограничения

- Неподписанный exe может ловить предупреждение SmartScreen — для раздачи нужен
  Authenticode-сертификат (или установщик с подписью).
- Сторож ищет процесс по имени `claude` и опрашивает его раз в 0,7 с, поэтому запуск
  вне виджета успевает проработать до ~0,7 с и только потом гасится.
